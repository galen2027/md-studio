# MD Preview 发布部署方案

版本：v1.9.9；日期：2026-11-19；平台：Windows x64。本地构建交付，未上传公开 Release。

## 本次解决的问题

### 文件变更提示

“File Changed on Disk”表示触发了文件变更保护：磁盘内容被认为发生变化，而编辑器中还有未保存内容，所以暂停自动保存。截图本身不能确认一定有其他程序修改。

v1.9.8 的自身写入过滤只持续 500ms，延迟或排队的文件通知可能误触发。v1.9.9 改为比对最后读取/保存的磁盘快照，并在主线程消费通知、处理脏状态时再次复核。相同内容忽略；真正的外部内容冲突继续保护本地编辑，提示已汉化。

若新版仍出现“文件已被其他程序修改”：先保留当前编辑。要用当前编辑覆盖磁盘，按 Ctrl+S；要保留外部版本，先将当前编辑另存，再打开原文件。不要直接丢弃未保存内容。

### 分栏内容错位

左侧预览、右侧源码改为两个独立滚动区域，按标题、段落、列表项、表格行和代码块的源码位置同步，不再共用一个长页面滚动条。右侧光标跨段落或搜索替换定位时，左侧将对应内容带入屏幕；鼠标滚动任一侧，另一侧同步到对应段落。

两栏的自然高度仍会不同，不强行拉大源码行间距。块内采用位置插值，特别长的单个段落、自定义 HTML、缺少细分锚点的内容只能近似定位，不能保证每一像素完全对齐。调整窗口宽度、缩放或图加载后重新建立对应关系。打印恢复完整页面流，不把屏幕分栏高度带进导出。

### Mermaid 节点编辑

保留点击图形放大、滚轮缩放、空格加左键拖动、PNG 高清 3 倍和 SVG 原始图下载。放大窗口新增“编辑节点”：点选节点，修改文字、删除节点及关联连线、撤销上次图修改。普通预览与所见即所得文字编辑模式均可使用，结果保存回原 Markdown。

修改先进行解析、其余节点和连线对比、图形渲染，再备份原文件并应用源码补丁。重复内容的多张图按文档顺序定位，只改选中的一张。无法准确定位或校验失败时不应用。

## 必需和可选依赖

必需 Windows x64 与 Microsoft Edge WebView2 Runtime。Windows 11 通常自带，裁剪系统仍可能缺失；缺失时程序提供原生提示。官方入口：[WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

无需另外安装 VC++ Runtime、Node、Python、Rust、Vditor、Mermaid 或 KaTeX；程序静态链接 CRT，资源离线内嵌。直接导出 PDF 需要 Edge 或 Chrome；打开 DOCX 需要 Word、WPS 或 LibreOffice，生成 DOCX 本身不需要安装 Word。

本程序未做 Authenticode 签名，Windows 可能提示未知发布者。运行前核对来源和 SHA-256，不需要关闭系统安全保护。

## 安装与首次验证

1. **先退出全部旧版 MD Preview。** 单实例机制会把打开请求转交给仍运行的旧版；旧窗口未退出时，可能实际使用的仍是 v1.9.8。
2. 保留旧 EXE，将新 ZIP 完整解压到固定本机目录，不要在 ZIP 内直接运行。先用 MD 与图片目录的副本验证。
3. 在解压目录打开 PowerShell：

```powershell
Get-FileHash .\MD-Preview-windows-x64.exe -Algorithm SHA256
.\MD-Preview-windows-x64.exe --version
.\MD-Preview-windows-x64.exe --help
```

校验值应与上表一致，版本应为 `MD Preview 1.9.9`。About 中也可核对版本。

4. 双击 EXE，打开测试文档。若缺少 WebView2，按提示安装微软运行时，再重新启动。
5. 点击工具栏分栏按钮：确认左预览、右源码都有独立滚动条。将右侧光标移到正文较后位置，或滚动左侧，检查另一侧对应段落。Ctrl+H 搜索一个位于文档后部的词，应在两栏显示对应位置。
6. 点击 ✎ 开启所见即所得编辑，修改普通正文、标题、列表或表格，Ctrl+S 保存。源码/分栏入口继续保留。
7. 打开放大后的 Mermaid 图，点击“编辑节点”，再点图中的节点或从下拉框选择节点。编辑文字，点击“应用文字”；自动保存约一秒，Ctrl+S 立即保存。文字包含空格、引号、括号和换行均可输入。
8. 点击“删除节点及连线”，核对后再点确认按钮。删除会一并移除所有连接该节点的连线；其他节点和连线保留。需要恢复时点“撤销上次图修改”。
9. 下载 PNG 和 SVG，验证图形清晰；关闭放大窗口，切换标签再切回，检查修改后的图和文字。用其他文本编辑器打开 MD，确认更新的是原文件。
10. 验证满意后再设置默认打开方式。EXE 移动或改名后先运行一次，再在 Windows“打开方式”中选择新路径；不要指向失效的软链接。

## 备份、图片与配置

继续沿用 `%LOCALAPPDATA%\md-preview` 配置目录，既有 `MD_PREVIEW_CONFIG_DIR` 环境变量仍可覆盖位置。进入富文本编辑、应用图修改前，对当前磁盘原文件做精确字节备份，存入配置目录 `backups/`，文件名含时间、路径哈希及原文件名，以 `.bak` 结尾。不覆盖已有备份，不自动清理。未保存的新文档没有磁盘原文备份。

恢复时先退出程序并另外保留当前 MD；按原文件名和时间选中备份，将其复制到文档目录，去掉 `.bak` 并打开核对。确认内容正确后才替换要恢复的文档，不删除其他备份、图片、模板或配置。

图片仍按 MD 所在目录解析。迁移文档时一起复制图片目录并保持相对结构；绝对盘符路径要求另一台机器存在相应文件。用于显示的内部协议地址不会写入 Markdown。

## 边界与副作用

- 本版图编辑仅覆盖 flowchart / graph 节点，不提供拖拽、边文字编辑或其他 Mermaid 图类型的图形编辑；这些继续使用源码。
- 部分扩展节点/连线语法、复杂嵌套 fenced block 无法准确映射时，会提示使用源码。数字索引 `linkStyle` 的节点删除被阻止，避免删边后样式错位；文字编辑仍可尝试。
- 节点标签用 Mermaid 实体表达引号、括号等特殊字符，换行用 `<br/>`；源码外观可能变化。普通预览图编辑以目标代码块补丁回写；富文本整体编辑仍可能规范化 Markdown 排版和 CRLF。
- 图修改撤销仅在当前放大窗口的编辑会话内保留；关闭重开后重新建立会话。原有文字撤销栈不跨模式/标签保留。已经保存的修改可使用备份恢复。
- 自动保存直接写回原文件。只读或权限失败继续沿用另存为、放弃关闭、取消的恢复流程；失败后暂停自动保存，编辑内容保留。
- YAML 元数据保持只读展示并原样保留，修改使用源码模式。自定义 HTML、特殊扩展语法不保证所有编辑器视觉一致。

## 回滚

1. 退出 v1.9.9；仍有未保存内容时先另存，或明确选择放弃。
2. 启动保留的 v1.9.8 EXE；如需恢复默认关联，运行旧版一次并在 Windows 中重新选择。
3. 切回旧程序不会撤销已经保存的文档。需要恢复内容时，先保留当前文件，再从 `backups/` 复制对应原文恢复。
4. 没有数据库或配置迁移，不删除 MD、图片、template.docx、用户配置或备份。
