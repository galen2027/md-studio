# MD Preview 预览编辑模块设计

版本：v1.0；日期：2026-11-19；第一阶段：v1.9.7。

## 目标与边界

在预览中修改普通段落、普通表头及单元格文字，保存回当前 Markdown 文件；保留源码编辑、分屏、Mermaid 放大、空格拖动、高清 PNG 和原始 SVG 下载。

第一阶段不支持标题、列表、引用、粗体/链接/行内代码/图片/公式等复杂块的预览编辑，不提供表格增删行列。复杂单元格只读，不会转换或丢弃语法。第二阶段研究 Mermaid 节点文字编辑及其源代码映射。

## 项目与模块划分

保持同一 Rust 项目、单个便携 EXE，不拆新项目、不引入前端运行时或服务。当前单入口较大，新能力以独立模块接入，不整体重构历史入口。

| 模块 | 责任 |
| --- | --- |
| `src/preview_edit.rs` | 利用 pulldown-cmark 解析位置，筛选普通段落/单元格，输出 UTF-16 源码范围 |
| `assets/enhance/preview-edit.js` | 可编辑区域、纯文本粘贴、原文局部替换、组合输入 |
| `src/main.rs` 现有协调层 | 模式、脏标记、700 ms 自动保存、原文件写入、另存为、标签与外部修改冲突 |
| `assets/enhance/preview-enhance.js` | Mermaid/公式/表格增强、灯箱和图片下载 |

## 数据与交互

原 MD → 解析事件及源码位置 → 可编辑文字标记 → 页面局部编辑 → 替换对应源码片段 → 同一源码状态 → 既有保存 IPC → 原 MD。

点击工具栏“预览文字编辑（段落 / 表格）”启用。虚线框标明支持编辑的文字；点击输入、Enter 换行、Ctrl+Z/Y 撤销重做、Ctrl+S 保存；停顿自动保存。再次点按钮或在字段中按 Escape 结束预览编辑。复杂格式使用源码/分屏入口。修改内容按字面文字保存，输入 `**文字**` 不自动变成粗体。

只替换修改过的段落或单元格，其余 Markdown 的缩进、围栏、链接、YAML 和表格对齐声明保持原样。标记字符在修改片段内转为字符实体，换行保存为 `<br>`，避免管道符新增表格列或粘贴内容执行 HTML。换行编码沿用现有 textarea 保存路径：CRLF 在 DOM 中规范化为 LF，不承诺文件字节级完全不变。

源码是唯一真实数据。原文和 HTML 必须来自同一版本；发现源码已改变则停用旧映射。保存回调只确认匹配版本，编辑期间不重新挂载 DOM，保留光标、撤销栈和中文组合输入。标签切换、外部变化和只读保存失败继续使用既有状态流程。

## 选型与副作用

候选 Vditor / Milkdown 适合完整即时渲染编辑；本阶段只需受限文字修改，其全篇序列化、资源体积、启动开销和 Markdown 方言差异代价较大。因此先实现解析器位置映射原型；扩展复杂格式时再以真实样例比较编辑器引擎。

风险：富文本字段暂不能编辑；改动片段的源码可读性会因转义下降；HTML 布局和 textarea 换行存在差异；大文档需要性能测试。未知语法不会自动降级成普通文本。

参考：[Vditor](https://github.com/Vanessa219/vditor)、[ProseMirror Markdown](https://prosemirror.net/examples/markdown/)、[Milkdown](https://milkdown.dev/docs/guide/getting-started)、[TOAST UI 自定义块](https://github.com/nhn/tui.editor/blob/master/docs/en/custom-block.md)。

## 分期与验收

第一阶段：普通段落/表格的预览修改和原文件保存；中文/emoji/CRLF/YAML 源码范围；空白格、字面标记、换行；撤销重做、IME、保存回调、标签切换；既有图表下载回归。

第二阶段：独立 Mermaid 编辑模块，先限定普通 flowchart 的节点标签，定位节点 ID 与标签源码；保留原图点击放大，使用明确的编辑入口。复杂 subgraph、注释、样式、重复节点声明及不支持的语法回退到块级源码编辑。不得通过 SVG 文本反推整张图的代码。

回滚：保留原文件备份；关闭候选版，启动 v1.9.6。无数据迁移；已写入 Markdown 的文字修改需要使用文件备份或版本控制恢复。
