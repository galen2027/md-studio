无法启动或版本没变化

先退出全部旧版窗口，再启动新 EXE。缺少 WebView2 时按提示安装微软运行时。程序暂未签名，请核对发布 SHA-256 和文件来源。EXE 请放在固定的本机目录。

图片、保存与流程图

迁移文档时同时复制相对图片目录。只读文件无法覆盖时选择另存为，或明确放弃/取消。流程图从放大窗口的“编辑节点”进入；复杂语法和其他图类型使用源码编辑。

如何报告问题

请在 本仓库 Issues 提供程序版本、Windows 版本、复现步骤和脱敏后的最小 Markdown 示例。可附截图及本地诊断日志中相关片段；不要提交凭据、内部地址或完整业务文件。
