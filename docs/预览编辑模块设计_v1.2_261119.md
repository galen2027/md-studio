# MD Preview 预览编辑模块设计

版本：v1.2；日期：2026-11-19；适用 v1.9.9。在 v1.1 的离线 Vditor 模型上增加三个模块能力，不拆分新的项目或服务，不升级依赖。

## 需求与范围

修复误触发的外部文件冲突保护；解决预览与源码高度不同导致分栏错位；在原有图表灯箱中点选节点、编辑文字、删除节点及关联连线，保存回原 Markdown。保留文字编辑、图片引用、图表缩放/平移及原始 SVG、高清 PNG 下载。

图编辑第一阶段覆盖 flowchart/graph 节点。拖拽、其他 Mermaid 图类型、边标签编辑不属于本次；数字索引 linkStyle 的节点删除、无法准确定位的扩展语法回退源码，避免损坏图。

## 磁盘版本判定

旧代码只在自身保存后 500ms 内比对内容。操作系统延迟通知、排队中的旧通知或保存时短暂的文件截断，都可能绕过该时间窗。截图只能证明触发了冲突保护，不能单凭截图判定一定存在外部程序修改。

新版本维护最后读取/保存的磁盘内容快照，不依赖固定时间窗。通知回调、主线程收到通知及前端返回脏状态时复核内容；与快照相同则忽略。真正发生外部内容变化且本地有未保存编辑时，暂停自动保存、保留编辑并用中文说明恢复方式；显式 Ctrl+S 是用户选择覆盖磁盘版本。干净文档加载外部内容后更新快照。

## 分栏同步

`src/source_map.rs` 使用 pulldown-cmark offset iterator，为标题、顶层段落、列表项、表格/行、引用、代码块增加源码位置属性。UTF-8 字节位置转换为 textarea 使用的 UTF-16 位置，并考虑 CRLF 与前置 YAML，不增加页面包裹层。

`assets/enhance/split-sync.js` 使用与源码框同字体、宽度、内边距和折行规则的隐藏镜像，建立源码位置、源码像素位置与预览块像素位置的对应关系。两栏分别滚动，块间插值同步；光标跨块时将对应预览位置带入屏幕。通过预期滚动位置抑制程序触发的反向滚动，避免反馈循环。

窗口尺寸、内容、图片及 Mermaid 高度变化时重建映射并保留语义位置。切回阅读模式定位到对应块。打印强制恢复普通页面流和完整高度，不把分栏视口当成单页导出。

同一屏可以对应到相同章节、段落、列表项或表格行；不同字体和排版下不承诺逐行像素完全一致。超长单个段落或特殊 HTML 使用相邻块间插值。

## 图形编辑与回写

`assets/enhance/mermaid-edit.js` 提供独立的源码补丁和界面。点击图形仍进入原灯箱，再点“编辑节点”；直接点 SVG 节点或用节点下拉框选择，蓝色轮廓标识当前节点。文字表单支持中文、引号、括号和换行；特殊字符按 Mermaid 实体转义。

使用当前内嵌 Mermaid 自身解析器获取节点和边的模型，编辑时定位节点声明并替换标签。删除时拆解受影响的连线链和节点组，删除目标及关联连线，保留其他节点定义、连线和样式。修改前后对比其余节点属性、边端点/文字/类型/样式，任何意外变化均拒绝应用。忽略解析器生成的 DOM ID 计数差异。

在解析、比对和渲染全部成功后，请求原文件精确备份；确认文档内容和标签未变化，再替换所选 Mermaid fenced block 的内容。多张内容相同的图按文档顺序匹配，不通过全文字符串替换。普通预览更新同一 textarea 状态并请求 Rust 渲染；富文本模式通过 Vditor setValue 保持编辑模式及内部撤销链，再复用同一自动保存 / Ctrl+S。

图修改撤销在灯箱当前会话中保存先前源码，关闭重开后不保留。删除有二次确认，提示同时删除关联连线。所有图操作继续使用原有只读保存失败恢复流程；备份失败不应用。

## 资源与兼容性

无新增下载依赖。Vditor、Lute、Mermaid、KaTeX 继续使用已有固定版本和资源；Mermaid 保持 strict 安全模式。灯箱为编辑面板预留空间并重新计算适配比例；窄窗口工具栏换行，空格输入不会触发拖图。

语法依据：[Mermaid 官方流程图文档](https://mermaid.js.org/syntax/flowchart.html)。实际支持能力以本机内嵌版本的解析与回归为准，不假定支持官网最新扩展语法。

## 验证与回滚

Rust 新增中文/emoji、YAML、CRLF 偏移，以及列表/表格行无额外包裹层测试。Windows 原生入口 `scripts/verify-preview-workflows.mjs` 验证同内容通知、真实冲突、双向分栏、节点点选及编辑/删除/撤销、重复图、富文本回写、桌面和390px。原有文字编辑、图片连续保存和 SVG/PNG 下载继续回归。

运行全门禁可设置 `MD_PREVIEW_VERIFY_NATIVE=1`，在 Windows 加跑原生工作流。真实业务文件只测试副本；调试版的测试警告日志入口不包含在 Release 中。已知未验证项目记录在部署说明。

回滚时关闭 v1.9.9，启动保留的 v1.9.8。没有数据库迁移；需要撤回文档改动时先保留当前文件，再从配置目录 backups 选择对应原文恢复。不得删除其他图片、模板或配置。
