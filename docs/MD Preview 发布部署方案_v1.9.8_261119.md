# MD Preview 发布部署方案

版本：v1.9.8；日期：2026-11-19；交付平台：Windows x64。本包为本地构建交付，未上传公开 Release。

## 本次变化

替换 v1.9.7 覆盖不足的预览编辑原型，采用固定 Vditor 4.0.1 所见即所得编辑器。标题、含粗体/斜体/链接/行内代码的段落、嵌套和有序列表、引用、表头、富文本及空白单元格都可以在排版后的界面修改，保存回同一 MD 文件。

编辑器资源内嵌，仅在点击编辑按钮时加载；保持单项目、单 EXE，无服务器和 Node 运行依赖。进入前自动备份原文，备份失败时阻止进入。打开但没有修改时不重写文档。

保留原有源码编辑、左右分屏、搜索替换、只读保存恢复、本地图片加载和导出功能。Mermaid 仍可点击放大、滚轮缩放、空格加左键拖动、下载原始 SVG 和 3 倍 PNG。直接在图形中修改节点文字仍待后续开发。

## 必需和可选依赖

必需：Windows x64 和 Microsoft Edge WebView2 Runtime。继续使用系统 Evergreen Runtime，未捆绑 Fixed Runtime；缺失时显示可操作提示。微软官方安装入口：[WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

无需另装：VC++ Runtime、Node.js、Python、Rust、Mermaid、KaTeX、Vditor。EXE 静态链接 CRT，编辑与渲染资源离线内置。

可选：Edge 或 Chrome 用于直接导出 PDF；Word、WPS 或 LibreOffice 用于查看 DOCX。生成 DOCX 本身无需安装 Word。

## 安装和首次使用

1. **先退出所有旧版 MD Preview 窗口。** 单实例机制可能把新 EXE 的打开请求转交给仍在运行的旧版，因此必须先退出再启动。
2. 保留旧 EXE，将 ZIP 解压到固定的本机目录。不要直接在 ZIP 内运行。先用文档及图片目录的副本试用。
3. 在解压目录打开 PowerShell，执行：

```powershell
Get-FileHash .\MD-Preview-windows-x64.exe -Algorithm SHA256
.\MD-Preview-windows-x64.exe --version
.\MD-Preview-windows-x64.exe --help
```

哈希必须与上表一致；版本必须显示 `MD Preview 1.9.8`。也可在程序 About 中核对。

4. 双击 EXE，打开 MD 文件。提示缺少 WebView2 时按提示安装微软运行时，然后重新启动。
5. 点击窗口顶部工具栏中，分屏按钮后面的 **✎ 按钮**；悬停提示为“所见即所得编辑（标题 / 段落 / 列表 / 表格）”。等待备份和编辑器加载完成，出现格式工具栏后即可编辑。
6. 直接点击正文、标题、列表或表格输入。Enter 创建段落；工具栏可设置标题、粗体、链接、列表和表格等。Ctrl+B 加粗，Ctrl+I 斜体，Ctrl+Z/Y 撤销/重做。
7. 停顿约一秒自动保存；Ctrl+S 立即保存。外部文本编辑器打开原 MD，确认已更新；切换标签再切回来检查结果。
8. Ctrl+F 在当前编辑内容中搜索；Ctrl+H 沿用源码替换界面。再点 ✎ 退出所见即所得编辑；原有源码编辑和分屏按钮仍可使用。
9. 点击 Mermaid 图检查放大、拖动及 PNG/SVG 下载。修改 Mermaid 语句使用代码块或源码编辑；本版本没有图形节点文字编辑器。
10. 确认使用正常后再设置默认打开方式。EXE 移动或改名后先运行一次，再用 Windows“打开方式”选择新路径；避免指向已失效的软链接。

## 文件路径、备份与恢复

图片仍按 MD 所在目录解析。迁移文档时一起复制图片目录，并保持相对目录结构；绝对盘符路径要求目标电脑具有对应文件。内部显示协议地址不会写回 Markdown。

沿用配置目录 `%LOCALAPPDATA%\md-preview`，既有 `MD_PREVIEW_CONFIG_DIR` 环境变量可覆盖位置。每次进入所见即所得编辑，原文件的精确字节备份放入配置目录的 `backups/`，文件名包含时间、路径哈希和原文件名，以 `.bak` 结尾；不覆盖已有备份，不自动删除。未保存的新文档没有原文件，因此没有原文备份。

恢复步骤：退出程序，先将当前 MD 另存一份；在 `backups/` 按原文件名和时间选取备份，将其复制到文档目录并去掉 `.bak` 后缀，再打开检查。只有确认恢复内容正确后才替换需要恢复的文件。不要删除其他备份或图片。

## 编辑副作用和边界

- 实际修改后，编辑器会重新序列化 Markdown，列表符号、空白和表格对齐等源码排版可能规范化；CRLF 沿用现有 textarea 的 LF 规范化行为。不能承诺只修改某几个源字符。
- YAML 元数据原样保留并在编辑器顶部只读显示，需要修改时使用源码模式。自定义 HTML 或特殊扩展语法可能以源码块显示；不承诺与所有其他 Markdown 工具视觉一致。
- 撤销历史在本次编辑模式内有效，切换模式或标签后不保留。需要撤回已保存文档时使用原文备份或版本控制。
- 自动保存直接修改原文件。只读/权限失败继续提供另存为、放弃关闭或取消，不应反复强制保存；失败后暂停自动保存，编辑内容保留。
- 打印和 PDF 先同步当前内容，再由原 Rust 渲染链路生成预览，避免使用旧预览；导出时会结束所见即所得编辑。DOCX 也使用当前源码。

## 回滚

1. 退出 v1.9.8；存在未保存内容时先另存为，或明确选择放弃。
