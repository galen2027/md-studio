Markdown Studio 隐私说明

更新时间：2026-11-19。适用本仓库发布的 Windows 桌面版，不替代上游移动应用的隐私说明。

本地文件与设置

程序在本机读取和编辑用户打开的 Markdown、图片和可选 DOCX 模板。没有用户账号、遥测或分析服务。自动保存会直接修改文件；原文备份、会话、窗口设置和诊断日志保存在本地配置目录，默认 %LOCALAPPDATA%\md-preview。日志和会话可能包含文件路径。备份不自动清理。

网络访问

程序会在首屏后查询本仓库 GitHub Releases，检查新版本；下载更新由 GitHub 提供。更新检查不上传 Markdown 正文、图片或文档目录。GitHub 会按其服务规则处理网络请求。

用户文档中的远程图片、链接等外部资源可能产生网络访问；点击外部链接会打开相应网站。这些资源由文档内容决定，不属于离线内嵌的渲染库。

导出与问题反馈

DOCX 在本地生成；直接导出 PDF 调用本机 Edge 或 Chrome。提交公开 Issue 前请自行移除日志、截图或示例文档中的账号、令牌、内部地址和敏感路径，维护者不会要求发布完整业务原件。
